# Settings ledger

Generated by `tools/gen-settings-ledger.py`. Do not edit by hand: run the
script. Every number below is measured from the files named at the top of
that script on the machine it ran on.

This is the checklist for one question: **of everything an engine is expected
to understand, what does HFW understand today?** It is not a wish list and it
is not a design. It is a countable inventory, so that progress is a number
instead of a feeling.

Three rules come out of this file, and they are the point of it:

1. **No surface may offer a setting the engine ignores.** A control that does
   nothing is worse than an absent one; the app hides or disables anything
   whose row here is not `applied`.
2. **`missing` is a to-do with a cost attached, never a permanent no.** Every
   row gets implemented, or gets a written reason in its tier.
3. **The finish line is 100% `applied` or `n/a`.** No row is deleted to make
   the percentage move.

## What the columns mean

| Column | Meaning |
|---|---|
| Setting | the name in the shared PrusaSlicer config dialect |
| Tier | Cost class, assigned by rule (see below) |
| Status | measured against HFW's parser and profiles today |
| HFW key | the key HFW uses for it, when the names differ |
| Type / Default / Unit | from the engine's definition table |
| Location | which config box it belongs to: Print, Filament, Printer, Tool, Object |

Status values:

| Status | Meaning |
|---|---|
| `applied` | HFW reads this name and the value changes the G-code |
| `partial` | HFW reads a related name but the semantics differ; the note says how |
| `missing` | HFW has no name for it and would reject the key |
| `n/a` | not applicable to a Klipper FDM target; excluded with a reason |

Tier rules:

```
Tier 0e — emit only: the value is a string or flag written into the output file.
Tier 0m — display metadata: price, density, spool weight; the G-code does not change.
Tier 0p — plumbing: printer geometry, firmware dialect, extruder counts.
Tier 1 — constant: a number threaded into a decision HFW already makes.
Tier 2 — algorithm: requires slicing work beyond threading a value.
Tier n/a — not applicable to a Klipper FDM target (SLA, colour mixing, Bambu fork).Tier int — not surfaced by any UI and not read here; excluded, with the reason on the row.
```
