# The documents, and what each one is for

Twenty documents live here. Each has one job, and no two answer the same
question. "Generated" means a script writes it — edit the script, never the file.

## Start with these

| document | answers | state |
|---|---|---|
| `START-HERE.md` | the whole picture: both projects, how they fit, what to run, how to work on this with the agent | written 2026-11-19 |
| `STATUS.md` | where the engine stands, in two minutes, with the command behind every number | current |
| `ROADMAP.md` | the order of work, and why that order | current |
